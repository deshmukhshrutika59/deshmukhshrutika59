## 🚀 Featured Projects

### 🔍 Enterprise Knowledge Copilot
<sub>Agentic RAG • Enterprise AI • Knowledge Retrieval</sub>

An Agentic RAG system designed to retrieve and synthesize enterprise documentation while ensuring responses are grounded in verifiable evidence.

**What makes it interesting?**
- Hybrid retrieval using BM25 and dense vector search
- Reciprocal Rank Fusion (RRF)
- Cross-Encoder reranking
- LangGraph-based agent orchestration
- Evidence sufficiency checks and bounded retries
- Deterministic citation validation
- Supported, Partially Supported, and Insufficient Evidence response classification
- FastAPI backend and Streamlit interface

**Tech Stack**

`Python` `LangGraph` `FastAPI` `Azure OpenAI` `ChromaDB` `BM25` `RRF` `Cross-Encoder` `Pydantic` `Streamlit`
